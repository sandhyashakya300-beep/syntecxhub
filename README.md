# Data Analysis and EDA Projects

Welcome to the `syntecxhub` repository! This repository contains a collection of data analysis, exploratory data analysis (EDA), and data visualization projects. These notebooks demonstrate practical applications of Python and data manipulation libraries (like Pandas) to extract insights from various datasets.

## 📁 Repository Contents

This repository is organized into several key projects, each with its own dedicated Jupyter Notebook and specific README documentation.

### 1. Netflix Exploratory Data Analysis (EDA)
An exploratory data analysis project focused on uncovering trends, content distribution, and insights from a Netflix dataset.
*   **Notebook:** `netflix_eda.ipynb`
*   **Documentation:** `Netflix_EDA_readme.md`
*   **Summary:** `netflix_eda_summary.txt`

### 2. IPL Match Analysis
An in-depth data analysis project examining Indian Premier League (IPL) match data to evaluate team performances and match statistics.
*   **Notebook:** `IPL-analysis.ipynb`
*   **Documentation:** `IPL_Match_Readme.md`

### 3. Correlation Heatmap Visualization
A specialized notebook dedicated to generating and interpreting correlation heatmaps to identify relationships between different variables in a dataset.
*   **Notebook:** `correlation_heatmap.ipynb`
*   **Documentation:** `corr_heat_README.md`

### 4. Pandas CSV Reader Utility
A foundational project demonstrating how to efficiently read, handle, and process CSV files using the Pandas library.
*   **Notebook:** `pandas_csvReader_.ipynb`
*   **Documentation:** `CSV_Reader_Readme.md`

## 🛠️ Technologies Used
*   **Python:** The core programming language used across all notebooks.
*   **Jupyter Notebook:** The interactive environment used for developing and presenting the analysis.
*   **Pandas:** Heavily utilized for data ingestion, cleaning, and manipulation.
