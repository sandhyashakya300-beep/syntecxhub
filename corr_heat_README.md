# Correlation Heatmap Analysis using Python

A Python-based data analysis project that explores relationships between features in the Iris dataset using correlation matrices, heatmaps, and pair plots.

## 📌 Project Overview

This project demonstrates how to:

- Load and analyze dataset data
- Calculate feature correlations
- Visualize relationships using heatmaps
- Create pair plots for feature comparison
- Understand positive and negative correlations in data

The project uses the famous Iris dataset for visualization and exploratory data analysis (EDA).

---

## 🚀 Features

- Data preprocessing using Pandas
- Correlation matrix generation
- Correlation heatmap visualization
- Pair plot visualization using Seaborn
- Sorting correlation pairs
- Removing self-correlations for better analysis

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
